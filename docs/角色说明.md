## Bundler 是什么？

**Bundler 本身就是一个 EOA**（外部拥有账户），但它扮演的角色不同。

### 普通 EOA（用户）vs Bundler（打包者）

|               | 普通用户 EOA                                 | Bundler EOA                                                             |
| ------------- | -------------------------------------------- | ----------------------------------------------------------------------- |
| **身份**      | 控制 4337 智能钱包的人                       | 专门提交 UserOp 到链上的服务商                                          |
| **做什么**    | 用私钥签名 UserOp                            | 收集签好的 UserOp，调用 `entryPoint.handleOps()`                        |
| **付 gas 吗** | 不直接付（由 Paymaster 或账户 deposit 代付） | **付**。Bundler 发起链上交易，先垫付 gas                                |
| **收回 gas**  | —                                            | EntryPoint 执行完后将 gas 费退给 `beneficiary`（通常就是 Bundler 自己） |
| **类比**      | 写信的人                                     | 快递员                                                                  |

### 为什么需要 Bundler？

4337 的核心目标是**让没有 ETH 的智能合约钱包也能发起交易**。问题是：

```
以太坊的规则：只有 EOA 才能发起链上交易
4337 钱包是合约 → 它自己发不了交易
→ 需要一个 EOA 帮它提交 → 这就是 Bundler
```

流程：

```
用户(EOA) ──签名UserOp──→ Bundler mempool
                              │
Bundler(EOA) ──发送tx──→ entryPoint.handleOps([userOp1, userOp2, ...])
                              │
                         EntryPoint ──→ 验证 → 执行 → 退gas给Bundler
                                                │
                            gas 费从哪来？
                            ├── 方式1: 账户在 EntryPoint 有 deposit
                            ├── 方式2: Paymaster 代付
                            └── 方式3: 如果账户的 deposit 不够且没有 Paymaster,
                                EntryPoint 会调用 account._payPrefund() 让账户从自身 ETH 余额即时补交。deposit 只是预存，让流程更高效
```

### 测试里的 bundler

```solidity
bundler = makeAddr("bundler");  // 一个普通地址
```

```solidity
vm.prank(bundler, bundler);  // 同时设置 msg.sender 和 tx.origin
entryPoint.handleOps(ops, beneficiary);
```

v0.9 EntryPoint 要求 `tx.origin == msg.sender` 且调用者无合约代码（即必须是 EOA），这就是为什么我们用 `vm.prank(bundler, bundler)` —— 模拟一个 EOA 发起交易。

如果用测试合约本身调用 `handleOps`，`tx.origin != msg.sender` 或 `msg.sender` 有代码，EntryPoint 会 revert `Reentrancy()`。

### 简单总结

- Bundler **就是** EOA，但角色是**代为提交交易的服务商**
- 用户签 UserOp → Bundler 把它打包成真正的链上交易
- Bundler 先垫 gas → EntryPoint 从账户/Paymaster deposit 里扣费 → 退给 Bundler
- 现实中 Bundler 是 Alchemy、Pimlico、Stackup 这类服务商运行的节点
- EntryPoint 中记录了所有交互过的4337账户的nonce
- EntryPoint 中记录了所有交互过得4337账户的预付gas余额,如果没有Paymaster, EntryPoint 会从这个deposit里扣gas
